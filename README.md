# ❤️ Like Button

A simple and interactive **Like Button** project created using **HTML, CSS, and JavaScript**. The project allows users to click a button to like or unlike an item with a visual change.

## ✨ Features

* ❤️ Like and unlike functionality
* 🔢 Like count display
* 🎨 Interactive button design
* 🖱️ Click event handling
* ⚡ Instant UI updates
* 📱 Simple and responsive design

## 🛠️ Technologies Used

* **HTML5** – Structure
* **CSS3** – Styling and design
* **JavaScript** – Button functionality and DOM manipulation

## 📌 Project Objective

The objective of this project is to understand how to create an interactive button using **HTML, CSS, and JavaScript**.

## 🎯 Concepts Practiced

* DOM Manipulation
* Event Listeners
* JavaScript Functions
* Variables
* Conditional Statements
* Click Events
* CSS Styling
* Dynamic Content Updates

## 🚀 How It Works

1. The user clicks the **Like** button.
2. JavaScript detects the click event.
3. The button changes its appearance.
4. The like count is updated.
5. Clicking again can remove the like.

## ▶️ How to Run

1. Clone the repository:

```bash

```

2. Open the project folder.
3. Open `index.html` in your browser.
